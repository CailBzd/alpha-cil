## ui

Fair — the design-system sweep (indigo/emerald tokens, `packages/ui` Button/Input/Select/Alert, loading spinners, empty states) is genuinely thorough and consistently applied on every page reviewed (calendrier, finances, projets/devis, recherche-adresse, artisan profil/société all have loading + empty + error states wired up); the real debt is a systemic non-responsive dashboard shell, no confirmation on irreversible deletes, and the artisan persona's nav being hand-duplicated instead of shared like the other two personas.
