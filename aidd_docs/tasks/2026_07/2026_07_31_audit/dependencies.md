## dependencies

Fair: `pnpm audit` (via `corepack pnpm audit`, ran clean, tooling worked) found 4 known CVEs, but all are bundled *inside* `next`'s own pinned `postcss`/`sharp` versions rather than in code this app actually exercises today (no `next/image` usage, no remote image patterns configured) — so nothing is actively exploitable right now, but several deps are 1-2 majors behind and one MIT-adjacent package (`react-leaflet`) ships under a non-OSI "ethical source" license worth a legal glance. No unused dependencies found in the sample checked (next-themes, recharts, @react-pdf/renderer, leaflet/react-leaflet, class-variance-authority, clsx, tailwind-merge, lucide-react, resend all have live imports), no duplicate/conflicting versions across the workspace (single resolved version each of react, react-dom, typescript, @types/node in `pnpm-lock.yaml`), and no GPL-family licenses or postinstall/build scripts beyond the explicitly-allowlisted `sharp` build (`pnpm-workspace.yaml` `allowBuilds`).
